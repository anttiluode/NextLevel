01 / Held-out memory retrieval

Every episode is a fresh random key/bit stream. The query names one previously written key. Classify its most recent bit. Results are test accuracy, not pixel reconstruction, language modelling or neural physics. The pilot was exploratory, not preregistered.

02 / The learned computation

128 keys + bit stream
learned phase writer→8 × 8 byte phase field
64 B evolving state→query-selected source
two ordered port reads

The query selects a hard launch site using a straight-through softmax approximation. It also learns an AB/BA preference. Paths themselves remain prescribed 12-step grid routes, and the selected source is chosen from a fixed known 128-key vocabulary.

The critical distinction

A trainable address table can change its assignments without discovering a better geometry. The real test is whether it outperforms its frozen, identically initialized version. In this pilot, it does not.

03 / What the ratio actually measures

z_AB = exp(i · (source + common))
z_BA = exp(i · (common + port))
ratio = z_AB · conj(z_BA)
      = exp(i · (source − port))

The port is fixed at zero phase, so the exact ratio reveals the directly addressed source phase. We measured discrepancies below about 1.1 × 10⁻⁶ on actual trained states. The direct-site reader solves the same information problem without two long paths. A successful ratio is therefore not a novel memory-capacity result.

Compute qualification

This PyTorch implementation evaluates 63 candidate paths before selecting one. A hardware implementation could route a single selected path, but that still costs two 12-step transmissions rather than one direct-site access.
